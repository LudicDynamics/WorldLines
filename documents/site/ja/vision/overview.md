## ひとことで言えば

言語モデルと agent は、物語を生成するだけのものではないと私たちは考えています。法則とエンジンと境界条件を与えれば、世界そのものをシミュレートできます。世界シミュレーションはそれ自体がゲームになりますし、すべてのキャラクター agent と世界をひとつの土台にして、その上にゲームを作ることもできます。

私たちは、このシミュレートされた世界の中で、すべてのキャラクターがプレイヤーとともに本当に生きていると信じています。世界に生きるキャラクターだけが、本当のキャラクターです。

WorldLines は、あなたと AI キャラクターが、果てのない世界をともに遊ぶ場所です。キャラクターには自分の目標と記憶があり、譲れない一線があります。世界には固有の場所と時間があり、ルールと因果があります。どれも、あなたのために前もって書かれた台本ではありません。

## 五つのこと

取り組んでいることはいくつもあり、しかもそれぞれ性質が違います。そこで、一つずつ別の記事にしました。

| 取り組み | ひとことで | 記事 |
|---|---|---|
| **物語は対立から生まれる** | 世界シミュレーションとキャラクター agent がそれぞれの立場を譲らず、そのぶつかり合いから物語が生まれる。それを起こすエンジンを私たちが作ります | [物語は対立から生まれる](/docs/vision/story-from-conflict) |
| **誰でも書ける編成** | TRPG からマーダーミステリーまで、一局の進め方はひとことで決められるべきもの。編成は、誰もが提供できるコンテンツになります | [言葉にすれば規則になる編成](/docs/vision/orchestration-for-everyone) |
| **それぞれの層を独立に** | キャラクターと世界を切り離し、素材・設定・プレイも切り離す。それぞれが得意な層だけを作り、残りはエンジンが組み立てます | [キャラクター、世界、素材、プレイ:それぞれ独立に](/docs/vision/decoupling) |
| **重いフロントエンドを定義し直す** | 下層の AI エンジンに求めるのは速さと自由だけ。どんなフロントエンドをつないでも、それがそのまま重いフロントエンドになります。エンジンを速く、堅牢に保つのが私たちの仕事です | [重いフロントエンドを定義し直す](/docs/vision/heavy-front-end) |
| **オープンソースとプラットフォーム** | エンジンはオープンソースで、自分の API キーがあれば動く。プラットフォームは、環境構築に手間をかけたくない人のためのもの。世界もキャラクターも編成も、コミュニティから生まれます | [開かれたエンジン、みんなのためのプラットフォーム](/docs/vision/open-engine) |

<!-- section: thread -->
## 五つを貫く一本の線

生成 AI は、尽きることのない物語を私たちにもたらしました。けれど私たちが欲しいのは、終わらなくてもよい物語です。

動き続ける世界の中なら、人も、AI キャラクターも、その両方が入り混じった顔ぶれも、好きなだけ遊び続けられます。世界は一拍ずつ前に進み、それぞれが都合のよいときに行動を出します。あなたが席を外しているあいだは、あなた自身の agent がキャラクターを演じ、戻ってきたらまた引き継げばよいのです。戻って最初に口にするのは、きっとこの問いです。「いないあいだに、何があった?」
