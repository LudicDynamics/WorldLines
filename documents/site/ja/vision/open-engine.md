## オープンソースの部分

エンジンの NeonRP は Apache-2.0 で、プロダクトの WorldLines は AGPL-3.0 で公開しており、どちらも [GitHub](https://github.com/LudicDynamics/WorldLines) にあります。世界、キャラクター、テンプレート、プレイ契約、ルールパックの仕様も、すべて公開しています。

オープンソース版は、あなた自身の API キーで動きます。DeepSeek でも、OpenAI 互換のサービスでも、独自のエンドポイントでもかまいません。世界も、キャラクターも、セーブも、あなたのマシンにあるただのファイルです。PyPI のパッケージでは二拍のターンをそのまま遊べ、ソースからインストールした場合は一拍で遊びます。詳しくは[モデルをつなぐ](/docs/players/providers)をご覧ください。

<!-- section: platform -->
## プラットフォームの部分

[worldlines.gg](https://worldlines.gg) と iOS アプリは、それ以外の人のためのものです。インストールするものも、設定するキーもありません。Hub で世界を一つ選べば、そのまま遊べます。

アカウントを持つと、ローカル版にないものが加わります。相談がまとまったかどうかを 1 秒以内に見きわめる判定役 Jev。公式の世界。自分で作った世界の公開。遊び終えた一局の共有。

<!-- section: one -->
## どちらも同じエンジン

ローカル版とプラットフォームは、同じエンジンを同じ仕様で動かしています。ローカルで作った世界は Hub に公開でき、Web やスマートフォンで遊んでもらえます。キャラクターは記憶を持ったまま、両者のあいだを行き来します。

エンジンをプラットフォームの中に閉じ込めるつもりはありません。自分で動かせる人は自分で動かし、手間をかけたくない人はプラットフォームを使う。どちらが遊んでいるのも、同じ種類の世界です。

<!-- section: community -->
## コミュニティ

世界も、キャラクターも、編成も、私たちだけが供給するものであってはなりません。開かれたエンジンと公開の仕様があるのは、コミュニティがそれらを生み出せるようにするためです。

質問、バグ報告、自作の世界のお披露目、コードへの変更の提案は、どれも [Discord](https://discord.gg/HJYWbdqWrE) と GitHub でお待ちしています。
