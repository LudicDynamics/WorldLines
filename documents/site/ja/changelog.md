## 1.0.3 — GitHub から入れる、worldlines.gg でオンラインプレイ(2026-10-24)

- **入手先** — ローカル版(`worldlines` = ローカル Web UI · `neonrp` = ターミナルのランチャー)は[このリポジトリ](https://github.com/LudicDynamics/WorldLines)/ PyPI から。[worldlines.gg](https://worldlines.gg) はオンラインプレイ。どちらのコマンドも起動時に自動更新(先に確認したい場合は `/update mode prompt`)
- **状態は速く書いて後から直す** — 1 拍の状態はまず速いパスで確定し、思考するパスが背後で地の文を読み直して数秒後に修正。TUI でも Web でも見える
- **判定役がなくてもまとまる** — Jev もアカウントもないとき、相談がまとまったかはそのランのモデルが判定。`/login` で Jev をオン
- **離れたキャラクターも歩く** — 町をまたぐ移動は街道を歩き、世界の日付どおりに到着。瞬間移動しない
- **TUI** — タブ付き `/status`、スキル · 対象 · 人 · 場所のスラッシュ補完、入力欄の上のクイックバー、ダイスの理由。`--mcp` モードは廃止
- **iOS とローカルの創作デスク** — デフォルトゾーンへの投稿、改版して再投稿、同じテンプレートから複数の作品。新しいプロダクトアイコン

- **プレイ層** — ダイスカード、状態変化タグ、自分にかかっている状態、エンディング画面;語りは一文字ずつ流れ、GM とキャラクターは別の段落に
- **止められる、固まらない** — 進行中のターンを「停止」できる;新しいプレイに切り替わるとページが自動で再接続;上にスクロールしても下へ引き戻されない
- **創作の書き戻し** — 編成グラフ、地図の道の追加・削除、プロットのトリガーを画面で直してそのままテンプレートへ
- **プレイ契約** — 公式の 4 種(謎解き TRPG · オープンアドベンチャー · マーダーミステリー · 恋愛コンパニオン);テンプレートが契約を宣言し、lint がそれで検査し、出口で精算
- **キャラクターライブラリの独立** — 世界にはキャラクターへのリンクだけを置き、開始時に実体化;一人が複数の世界へ、一つの世界に複数のキャラクター
- **エクスポート / インポート** — テンプレートとキャラクターを一つのパッケージにして持ち出し、また取り込む
- **仕様はフォルダの中に** — テンプレート、テンプレートライブラリ、キャラクターライブラリそれぞれに `AGENTS.md` · `CLAUDE.md` · `spec/`;Claude Code や Codex が開けばすぐ読める
- **修正** — 同じ秒に二つのプレイを始めても、遊んでいる方が消えない
- **内蔵ルールパック** — `rpg`(d20、SRD 5.2 を選択可)に加えて `pct`(サンドボックス TRPG、BRP パーセンタイルダイス、`rpg` の上に構築)と `monopoly`
- **モデルが止まっても待ち続けない** — ストリームの見張り:最初のトークン、またはトークン間の間隔が長すぎると再送;しきい値は環境変数で調整

## v0.4.0 — 一つのエンジン、二つの製品 (2026-08)

- **エンジン / シェル分離** — Web UI とデスクトップシェルをオープンソースの [WorldLines リポジトリ](https://github.com/LudicDynamics/WorldLines)(AGPL-3.0)へ移管;エンジンは極軽のシミュレーションコアへ収斂(`pip install worldlines` の使い方は不変)
- **誰が話すかはエージェントが決める** — world-agent が場を主宰:反応すべきキャラだけを起こし、答えが要るときは直接尋ね、キャラ側も世界が知るべきことは挙手して伝える
- **キャストへの直通線** — ターン外で `@名前` の一対一、`#` で場全体へ;キャラ自身の記憶から答え、世界時計は進まない
- **観察が独立した画面に** — 観察ページは三ペインのチャンネルガラス:チャンネル欄(◉世界 / #ここ / @キャラ)、ライブ面、在場レール
- **在場ハートビート** — 呼ばれなかった在場キャラも毎ターン軽い反応を返し、群像が凍らない
- **ダイスと物理検証つき移動** — `roll_check`(BRP d100 / SRD d20)がチェーンに;移動は全てマップ検証を通過
- **モードは二つだけ** — `orchestrator` と `multi-agent`;旧 `fast` は退役、旧セーブは静かに移行
- **修正** — 固まった LLM ストリームはタイムアウトしてリトライ梯子へ;セッションはリフレッシュで自己修復;長い生成が途切れない

## v0.2.10–v0.3.0 — LocalShell:エンジンが完全なローカル製品に (2026-07)

- **LocalShell** — `neonrp web` がプレイ画面から完全なローカル製品へ:ゲームファサード / 書斎(続きから・ワールド書庫) / 創作ゲート / PrePlay 確認 / プレイツールバー;デスクトップシェルと同一ビルド

- **ターンのロールバック** — 任意の過去ターンから git 式に分岐、現在の線は保持
- **インポートが完全な soul に** — SillyTavern カードを LLM が完全な soul へ補完;作成インタビューの AI 思考をリアルタイム表示
- **安定性** — CJK ワールド名を全面修正;Playwright e2e 基盤 + リリースゲート(テストが緑でなければ出荷しない)
