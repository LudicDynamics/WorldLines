## v0.4.0 — 一つのエンジン、二つの製品 (2026-08)

- **エンジン / シェル分離** — Web UI とデスクトップシェルをオープンソースの [WorldLines リポジトリ](https://github.com/LudicDynamics/WorldLines)(AGPL-3.0)へ移管;エンジンは極軽のシミュレーションコアへ収斂(`pip install worldlines` の使い方は不変)
- **誰が話すかはエージェントが決める** — world-agent が場を主宰:反応すべきキャラだけを起こし、答えが要るときは直接尋ね、キャラ側も世界が知るべきことは挙手して伝える
- **キャストへの直通線** — ターン外で `@名前` の一対一、`#` で場全体へ;キャラ自身の記憶から答え、世界時計は進まない
- **観察が独立した画面に** — 観察ページは三ペインのチャンネルガラス:チャンネル欄(◉世界 / #ここ / @キャラ)、ライブ面、在場レール
- **在場ハートビート** — 呼ばれなかった在場キャラも毎ターン軽い反応を返し、群像が凍らない
- **ダイスと物理検証つき移動** — `roll_check`(BRP d100 / SRD d20)がチェーンに;移動は全てマップ検証を通過
- **モードは二つだけ** — `orchestrator` と `multi-agent`;旧 `fast` は退役、旧セーブは静かに移行
- **修正** — 固まった LLM ストリームはタイムアウトしてリトライ梯子へ;セッションはリフレッシュで自己修復;長い生成が途切れない
