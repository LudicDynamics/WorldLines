<!-- section: what-caai-does-well -->
## Character AI が得意なこと

- 摩擦のないオンボーディング — キャラクターとのチャット開始がワンクリック
- 巨大なコミュニティのキャラクターカードライブラリ
- モバイルネイティブ

<!-- section: where-worldlines-differs -->
## WorldLines が違うところ

最も重要な違いは 2 つです:

1. **キャラクター中心ではなく、世界中心。** Character AI はチャット相手のキャラクターを与えます。WorldLines は、すべての AI ペルソナを **生きた世界の内側** に作ります — キャラクターは場所に存在し、イベント・他の agent・帰結に囲まれており、真空の中のチャットではありません。

2. **会話ではなく、持続するペルソナ + シミュレーション。** キャラクターの人格・記憶・関係性は **永続化** され — セッションを跨ぎ、さらには世界を跨いで引き継がれます（同じ Elena が Stoneford から Kagura Island へ渡れます）。そしてエンジンは対話ではなく **シミュレーション** を走らせます: agent は自ら行動し、世界はあなたがいてもいなくても進み、起きたことは保存・分岐・リプレイできるステートとして記録されます。

具体的には: 持続する世界 + キャラクターステート、マルチ Agent オーケストレーション、ファイルベース / git バージョン管理の世界、ローカルファーストなモデル（GLM / LM Studio / Ollama）、レビュー可能な Plan → Diff → Apply の変更。

<!-- section: who-should-use-which -->
## どちらを使うべきか

- お気に入りのキャラクターとのカジュアルなチャット → Character AI
- 保持・フォーク・進化させたい世界を作る／プレイする → WorldLines
