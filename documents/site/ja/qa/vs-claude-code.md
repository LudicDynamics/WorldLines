## 共通点

両エンジンとも同じエージェント型の土台の上に立っています:

- 構造化された proposal / diff / apply ループ
- 実ディレクトリ上に存在するファイルベースのステート
- 対話型ターミナルインターフェース
- コーパス全体ではなくワーキングセット上のリトリーバル
- 分岐とリプレイが可能なセッション履歴

Claude Code が**コード**のための IDE なら、WorldLines は**生きた世界**のための IDE です。直感はそのまま移植できます。

<!-- section: where-they-diverge -->
## 異なる点

|                  | Claude Code                       | WorldLines                              |
|------------------|-----------------------------------|-----------------------------------------|
| ドメイン         | コード編集 / ソフトウェア agent    | ゲーム世界 / AIRP agent                 |
| ステート単位     | ファイル + git                    | Event + Snapshot + Branch               |
| 主要ループ       | Plan → Edit → Test                | Plan → Diff → Apply → Save              |
| 同梱物           | リポジトリはご自分で用意          | `stoneford` スターターテンプレートを同梱 |
| サンドボックス   | シェル / コンテナ                 | エンジン内蔵の Sandbox + Replay をファーストクラスで |
| マルチ Agent     | タスクごとのサブ agent            | World-agent + ソウルの社会（村）+ ドメイン agent |

同じエージェント型の筋肉を、異なるドメインに向けている: コードベースではなく *世界* をターンを跨いで一貫させること。

<!-- section: fit-together -->
## どう噛み合うか

両者はライバルではありません —— WorldLines は Claude Code が広めたのと同じエージェント型パラダイムの *上で* 動き、Claude Code は WorldLines の世界を **オーサリング** する最良の方法のひとつです。

- **スキルでオーサリング。** WorldLines は Claude Code（と Codex）のオーサリングスキルを同梱しています —— リポジトリを clone し、Claude Code で開いて、欲しい世界を伝えるだけ; `game/` + agent + ソウルを雛形作成してくれます。[チュートリアル](https://github.com/LudicDynamics/WorldLines/tree/main/tutorials) を参照。
- **エージェント型で遊ぶ。** すでに多くの人が Claude Code の内側で直接ロールプレイしています。WorldLines はそこに足りないピースを与えます: 持続する世界、独立したソウルの社会（マルチエージェントの村）、save / branch / replay —— そして生のターミナルだけにならないようにするフロントエンド。

Claude Code がコードのための IDE なら、WorldLines はその同じエージェント型の筋肉を、生きて遊べる世界へと変えます。

<!-- section: what-we-push -->
## さらに推し進めること

すでに多くの人が Claude Code や Codex の内側でロールプレイしています —— 私たちはそれを歓迎します。その方向の上に、私たちは 3 つのことを解こうとしました:

1. **速度。** Claude Code / Codex は 1 ターンに **3 分以上** かかることがあります —— コーディングには問題なくても、プレイには苦痛です。私たちは **ロールプレイ向けにチューニングされた、より速い agent** を求めています。ターンがビルドではなく会話のように感じられるように。

2. **ロックインなし —— どんなモデルでも、ローカル & 無料でも。** ロールプレイが一社に縛られるべきではありません。**DeepSeek、OpenRouter、オープンソース、ローカル、無料** のモデルで動かし、**カスタマイズ可能** に保つ —— 頭脳はあなたが選びます。

3. **マルチエージェント、スケールして。** 私たちは **マルチエージェントの村** をさらに推し進めています —— より多くの独立したソウル、より大きなシーン、より大きな世界 —— そして、それらすべてを一貫させる **オーケストレーション** を革新しています。

Claude Code と同じエージェント型の精神を、コードベースの代わりに生きた世界へとチューニングしています。
