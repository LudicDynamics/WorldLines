## 2 つのパラダイム: プロンプティング vs エージェント

**SillyTavern** は、選んだ LLM に丹念に作り込んだ **プロンプト** を送るパワーユーザー向けの *フロントエンド* です。キャラクター、ロアブック、プロンプトマクロ —— プロンプト駆動のロールプレイにおける、チャット側で最高クラスのツールです。

**WorldLines はエージェント型です。** ひとつの LLM がプロンプトに答えるのではなく、**Claude Code** や **Codex** を支えるのと同じ種類のオーケストレーションシステムが世界を走らせます: 計画を立て、ツールを呼び、ステートを読み書きし、自ら行動する agent たち。私たちはキャラクターにプロンプトを与えるのではなく、キャラクターと、それを取り巻く世界を **シミュレート** します。

<!-- section: compatible -->
## 互換性を保ち続けたい

SillyTavern のキャラクターカードとワールドブックは優れたコンテンツフォーマットであり、私たちは人々が今いる場所に歩み寄りたいと考えています。SillyTavern のカードはすでにインポートできます:

```bash
neonrp import sillytavern-card card.png --id mira-ashford
```

方向性: SillyTavern フォーマットをインポート可能なまま保ちつつ、その上に **新しい遊び方** を提供する —— プロンプトを 1 つずつ送るチャットではなく、エージェント型のシミュレーション。

<!-- section: agent-roleplay -->
## 新しい種類のロールプレイ

すでに多くの人が、**Claude Code** や **Codex** の *内側で直接* ロールプレイし、エージェント型システムにキャラクターとシーンを動かさせています。それはプロンプトベースのフロントエンドが想定していた範囲をすでに超えています —— 私たちが **Agent Role Play** と呼ぶ新しいパラダイムです。

WorldLines はまさにこのために作られています: agent オーケストレーションを通じてペルソナと世界をシミュレートする。そして私たちは、エージェント型のロールプレイがそのパワーに見合うだけ心地よく感じられるよう、**フロントエンドの磨き込み** に投資しています —— 生のターミナルに住み続けることなく、走り続けるシミュレーションの深みを。

持続し、分岐し、本当に *シミュレートされる* 世界が欲しいなら WorldLines を選んでください。最大限のプロンプト柔軟性と確立された拡張エコシステムが欲しいなら SillyTavern を手に取ってください —— どちらにしても、カードはインポートできます。
