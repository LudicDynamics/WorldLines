<!-- section: how -->
## 使い方

`neonrp` で入るターミナルのゲーム内で、入力欄に `/` と打つとコマンドが補完つきで一覧されます。引数なしのコマンドの多くは選択画面を開くので、id を覚えておく必要はありません。

以下のコマンドのほかに、世界が自分のコマンドを持ち込むことがあります。グレイオーク館のスキル `/聞き耳` と `/目星` などです。`/` を打つと、エンジンのコマンドと並んで表示されます。

<!-- section: play -->
## 遊ぶ

| コマンド | 働き |
|---|---|
| `/open [世界またはセーブ]` | 引数なし:遊べる世界とセーブを一覧。セーブを指定:それを続ける。世界を指定:新しい一局を始める |
| `/init [世界]` | 世界で新しい一局を始める。引数なしなら選択画面で、そこから白紙の世界をゼロから作ることもできる |
| `/load [セーブまたはスナップショット]` | セーブを続ける、またはこの一局のスナップショットを読む。引数なしなら選択画面 |
| `/save [名前]` | この一局にスナップショットを保存 |
| `/undo` | 一手戻る |
| `/undo list` | この線のターンを一覧 |
| `/undo <ターン>` | そのターンに戻り、新しい線を始める。元の線は残る |
| `/redo` | いま戻した一手をやり直す |
| `/status [ページ]` | 状態パネル。ページ:`player` あなた · `agents` キャラクター · `plan` 計画ボード · `dice` ダイス · `settlement` エンディングと精算 · `contract` プレイ契約 · `account` アカウントと判定役 · `usage` 使用量 · `room` ネットワーク上の卓 |
| `/lang [言語]` | この一局の語りの言語:`zh` `en` `ja` `ko` |
| `/find <キーワード>` | この世界の場所、人物、持ち物を検索 |
| `/clear` | 画面上の会話を消す |

<!-- section: characters -->
## キャラクター

| コマンド | 働き |
|---|---|
| `/who [キャラクター]` | キャラクターの視点に入る:どこにいるか、何を覚えているか、直近の数ターンで何をしたか。そこから直接話しかけたり、代わりに行動したりできる |
| `/cast [キャラクター] [役]` | ライブラリのキャラクターを `npc` または `player` としてこの世界に迎える。引数なしなら迎えられる人を一覧 |
| `/create <名前>` | build モードで新しいキャラクターを作る。agent が書く |
| `/remove <キャラクター>` | キャラクターをこの世界から外す(ライブラリのコピーはそのまま) |
| `/reset <キャラクター>` | キャラクターにここでの記憶と経歴を忘れさせる。人物設定はそのまま |
| `/import <ファイル>` | ワールドパッケージ(`.zip`)または SillyTavern のカード(`.png` / `.json`)を取り込む。中身で判別する |

<!-- section: build -->
## 世界を作る

| コマンド | 働き |
|---|---|
| `/mode [build または play]` | 同じ世界の中で切り替える:build = agent にこの世界を変えさせる、play = 遊ぶ |
| `/vault [build]` | この世界を Obsidian の vault に投影して開く。`build` は書き出すだけで開かない |
| `/dev [項目]` | クリエイターと不具合調査のため:`graph` 編成グラフ · `dry-run` 1 拍だけ試走 · `beats` 本文に拍の骨組みを示す · `template` テンプレート · `validate` 世界をチェック · `mcp` · `bridge` · `debug` |

<!-- section: app -->
## アカウント、設定、更新

| コマンド | 働き |
|---|---|
| `/login` | Worldlines アカウント(任意):判定役 Jev、モデル中継、世界のアップロード。`/login code` はブラウザなしでログイン · `/login status` は状態を表示 · `/login out` はログアウト |
| `/settings` | モデル、キー、Discord ブリッジ、その他の設定 |
| `/update` | 更新を確認。`/update apply` で適用 · `/update status` でバージョンと設定を表示 · `/update mode auto`、`prompt`、`notify` で起動時の動作を設定 · `/update channel` で更新チャンネルを変更 |
| `/help` | コマンドを一覧 |
| `/quit` · `/q` | 終了 |

<!-- section: input -->
## 入力欄の記号

| 書き方 | 働き |
|---|---|
| `@名前` | キャラクターに話しかける。`@` を打つとその場にいる人が補完される |
| `@dm` | 進行役に先へ進めてもらう:相談からそのまま解決へ |
| 「決まり」 | 同じ。話がまとまったという意味 |
| `#` | 文の中で、場所と持ち物を補完する |

## 古いコマンドの行き先

1.0 からコマンドは上のものに絞られました。古いコマンドを打っても「不明なコマンド」にはならず、いま何を使うかが表示されます。

| 古いコマンド | いま使うもの |
|---|---|
| `/branch` | `/undo list` · `/undo <ターン>` |
| `/worlds` `/worldlines` `/continue` | `/open` |
| `/game` | `/open` · `/create` |
| `/sessions` | `/load` |
| `/models` `/auth` `/wl-model` `/locale` | `/settings` |
| `/load-world` | `/import` |
| `/export-world` | コマンドライン:`neonrp export-world` |
| `/context` | `/find` |
| `/replay` | `/dev dry-run` |
| `/compact` | `/clear` |
| `/copy` | `F6` |
| `/run` `/agent` | そのまま言う |
| `/index` | エンジンが自動で最新に保つ |
| `/skills` | agent が自分で使う |
| `/files` | コマンドラインの git |

一覧には出なくなりましたが、打てばまだ動くものがいくつかあります。`/validate`(`/dev validate` でも)、`/mcp`(`/dev mcp` でも)、`/bridge`(`/dev bridge` でも)、`/debug` と `/verbose`(`/dev debug` に統合)、`/stats`(いまは `/status usage`)、`/config`(ふだんは `/settings` を使う)。

`--mcp` 起動モードと Claude Code プリセットは 1.0.3 で削除されました。
