## 自動で保存

どの一局も `~/.worldlines/plays/` の中の一つのフォルダで、ターンが確定するたびに保存されます。手で保存するものはありません。閉じて、また開いて、続きを遊ぶだけです。

<!-- section: web -->
## Web で

プレイ一覧で世界をクリックすると、そのカードにセーブが並びます。

- **続ける**:一局を離れたところから続けます;
- **新しい一局を始める**:同じ世界をはじめから。前の一局はセーブに残ります;
- **削除**:一局を消します(もう一度確認されます)。

巻き戻しと特定のターンに戻ることは、いまのところターミナルだけです。Web UI とターミナルは同じセーブを共有します。Web で遊んだ一局は、ターミナルの `/load` で続けられます。

<!-- section: cmds -->
## ターミナルで

| コマンド | 働き |
|---|---|
| `/open` | 遊べる世界とセーブを一覧。`/open <セーブ>` はそれを続け、`/open <世界>` は新しい一局を始める |
| `/load` | 続けるセーブ、またはこの一局のスナップショットを選ぶ |
| `/save [名前]` | この一局にスナップショットを保存 |
| `/undo` | 一手戻る |
| `/redo` | いま戻した一手をやり直す |
| `/undo list` | この線のターンを一覧 |
| `/undo <ターン>` | そのターンに戻り、そこから新しい線を始める。元の線は残る |

新しい線が元の線を変えることはありません。元の線のすべてのターンがそのまま残ります。

<!-- section: under -->
## 背後にあるもの:コミットグラフ

どのターンも一つのコミットで、一局はコミットグラフです。[世界線](/docs/concepts/worldlines) を参照してください。ゲームの外では、その一局のフォルダに入って `neonrp commit log` を実行します。
