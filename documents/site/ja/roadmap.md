## リリース済み:1.0.x

すべての記録は[更新履歴](/docs/changelog)にあります。要点:

- **ローカルの二つの画面**:`worldlines`(ローカル Web)と `neonrp`(ターミナルのランチャー)。PyPI か GitHub からインストールし、起動時に自分で更新します。オンラインでは [worldlines.gg](https://worldlines.gg) と iOS アプリで遊べます
- **二拍のターン**:先に相談、次に解決。話がまとまったかは判定役(Jev、またはそのプレイ自身のモデル)が決めます
- **状態はまず書き込み、裏で確認し直す**。何が変わったかは知らせます
- **テンプレートとプレイ契約**:公式の契約が四つ(謎解き TRPG・オープン冒険・マーダーミステリー・恋愛コンパニオン)。公開前に契約に沿ってチェックします
- **キャラクターライブラリの独立**:世界にはキャラクターへのリンクだけを置き、一人のキャラクターが多くの世界に入れます
- **書き出し / 取り込み**:テンプレートとキャラクターを一つのパッケージで持ち運べます。SillyTavern のキャラクターカードもそのまま取り込めます
- **ローカル版に二つの世界を内蔵**:グレイオーク館とストーンフォード。ほかの公式世界は Hub にあります
- **オープンソース**:エンジン NeonRP(Apache-2.0)とプロダクト WorldLines(AGPL-3.0)はどちらも [GitHub](https://github.com/LudicDynamics/WorldLines) にあります

<!-- section: now -->
## いま作っているもの

- **公開の流れ**:アップロードした世界はまず下書きになり、審査のあと公開されます。アップロード前に秘密鍵、カバー、立ち絵、四言語のタイトルと紹介文をチェックします
- **プレイをリプレイに**:遊んだ一回をリプレイとして書き出し、Hub で共有します
- **公式世界を増やす**こと、そしていまの二つの世界をもっと安定して面白くすること
