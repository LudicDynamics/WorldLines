## 1.0.3 —— 从 GitHub 安装,在 worldlines.gg 在线玩(2026-10-24)

- **去哪里拿** —— 本地版(`worldlines` = 本地网页 · `neonrp` = 终端启动器)从[这个仓库](https://github.com/LudicDynamics/WorldLines)/ PyPI 安装;[worldlines.gg](https://worldlines.gg) 是在线游玩。两个命令启动时自动更新(想先问一声:`/update mode prompt`)
- **写状态先快后修正** —— 一拍的状态先用快版本落下,开思考的慢版本在后台复核、几秒后修正,TUI 和网页都看得到
- **没有判官也能谈妥** —— 没有 Jev、没登录时,商量拍谈没谈妥由这局自己的模型判断;`/login` 可开 Jev
- **不在你身边的角色也走路** —— 跨镇要走驿路、按世界日期到达,不再瞬移
- **TUI** —— 可切页的 `/status`、技能 · 对象 · 人 · 地点的斜杠补全、输入框上方的快捷栏、骰子理由;去掉了 `--mcp` 模式
- **iOS 和本地的创作台** —— 提交到默认区、改版再提交、同一模板多份作品;新产品图标

- **游玩层** —— 商量拍 / 清算拍分色、骰子卡、状态变化标签、身上的状态、结局画面;叙事逐字流出,主持和角色分开成段
- **能停、不卡** —— 回合进行中可以「停止」;换局后页面自动重连,不再卡在「主持在想」;往上翻不会被拉回底部
- **创作写回** —— 编排图、地图建路删路、剧情触发器,在界面上改完直接写回模板
- **玩法合约** —— 四份官方合约(解谜跑团 · 开放冒险 · 剧本杀 · 恋爱陪伴);模板声明合约,lint 按合约查,到出口写结算
- **角色库独立** —— 世界里只放角色的 link,开局才实体化;一个角色进多个世界,一个世界选多个角色
- **导出 / 导入** —— 模板和角色打成一个包带走、再导回来
- **spec 就在文件夹里** —— 每个模板、模板库、角色库都带 `AGENTS.md` · `CLAUDE.md` · `spec/`,Claude Code、Codex 打开就能读
- **修复** —— 同一秒开两局不再删掉正在玩的那一局
- **内置规则包** —— `rpg`(d20,可选 SRD 5.2)之外新增 `pct`(沙盒跑团,BRP 百分骰,建在 `rpg` 上)与 `monopoly`(大富翁);规格见 [规格](/docs/developers/specs)
- **模型卡住不干等** —— 流式看门狗:第一个字或两字之间等太久就重发,阈值可用环境变量调,见 [设置模型提供商](/docs/players/providers)

## v0.4.0 — 一引擎两产品 (2026-08)

- **引擎 / 壳分离** —— Web UI 与桌面壳迁入开源 [WorldLines 仓](https://github.com/LudicDynamics/WorldLines)(AGPL-3.0);引擎向极轻模拟内核收敛(`pip install worldlines` 用法完全不变)
- **谁发言,由 agent 决定** —— world-agent 主持场面:只唤醒该反应的角色,需要答案时直接去问某个角色,角色也会在世界该知情时主动举手
- **与角色的直连线** —— 回合之外 `@名字` 一对一、`#` 对全场,从角色自己的记忆作答,不走世界时钟
- **观察成为独立界面** —— 观察页以三栏频道玻璃打开世界:频道栏(◉世界 / #此地 / @角色)、实时流、在场栏
- **在场心跳** —— 在场但未被点名的角色每回合仍给一个轻反应,群像不再冻结
- **骰子与物理校验的移动** —— `roll_check`(BRP d100 / SRD d20)进入链路;所有移动过地图校验
- **模式收敛为二** —— `orchestrator` 与 `multi-agent`;旧 `fast` 模式退役,旧档静默迁移
- **修复** —— 挂死的 LLM 流会超时进入重试梯;会话刷新自愈;长生成不再截断
