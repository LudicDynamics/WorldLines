## 一句话

我们相信,语言模型和 agent 不只是用来生成故事的。它们可以做世界模拟:用法则、引擎和边界条件,把一个世界模拟出来。世界模拟本身可以是一个游戏;也可以把所有的角色 agent 和世界当成底座,在上面做游戏。

我们相信,在这个被模拟出来的世界里,所有的角色和玩家一起,真实地活在里面。只有活在一个世界里的角色,才是真正的角色。

WorldLines 让你和你的 AI 角色一起,在一个没有边界的世界里玩。角色有自己的目标、记忆和不肯让步的地方;世界有自己的地点、时间、规则和因果。没有哪一样是提前为你写好的剧本。

## 五件事

我们手上的事有好几件,每一件都不一样,所以每一件单独写了一篇。

| 事 | 一句话 | 文章 |
|---|---|---|
| **剧本从对抗里来** | 世界模拟和角色 agent 各有各的立场,剧本在它们的对抗中产生。我们做的是让这件事发生的引擎 | [剧本从对抗里来](/docs/vision/story-from-conflict) |
| **人人都能写的编排** | 从跑团到剧本杀,一局怎么进行,说一句话就能定下来。编排会变成人人都能提供的内容 | [言出法随的编排](/docs/vision/orchestration-for-everyone) |
| **各归各** | 角色和世界分开,素材、设定和玩法也分开。每个人只做自己擅长的那一层,剩下的由引擎装起来 | [角色、世界、素材、玩法,各归各](/docs/vision/decoupling) |
| **重新定义重前端** | 底层的 AI 引擎只需要快和自由,接上什么前端,就是什么样的重前端。我们负责把引擎做快、做稳 | [重新定义重前端](/docs/vision/heavy-front-end) |
| **开源和平台** | 引擎开源,用自己的 API key 就能跑;平台给不想折腾的人。世界、角色和编排来自社区 | [开源的引擎,给所有人的平台](/docs/vision/open-engine) |

<!-- section: thread -->
## 串起它们的一条线

生成式 AI 给了我们无穷无尽的故事。我们想要的,是不必结束的故事。

在一个一直在运行的世界里,人、AI 角色,还有两者的混合,可以一直玩下去。世界一拍一拍地往前走,每个人在自己方便的时候提交行动。你不在的时候,你的角色可以由你自己的 agent 接着演,等你回来再接手。回来的第一句话会是:我不在的时候,发生了什么?
