## 怎么叠加

> **状态:设计中 · 接口为拟定** —— 3.0 定下的设计,名字和字段在实装前可能还会改。

```yaml
template: rpg
mixins: [space, tick, economy, factions]
```

片段里的规则是 T2(不花 token),它们提出的改动和玩家一样要过 verify。片段声明「有哪些类、哪些 ops、增长策略是什么」,world agent 只能在这个范围里新增实例 —— 这就是 world agent 与 World Schema 之间的约定。

<!-- section: economy -->
## 经济片段

| 部分 | 内容 |
|---|---|
| 变量 | `stock.{镇}.{货}` · `price.{镇}.{货}` · `inv.{货}` · `econ.index` |
| 类 | `caravan`(商队,游玩中不断新增) |
| ops | `trade` · `new_caravan` · `deliver` · `rob` |
| 规则 | 产出 − 消耗;定价 `价 = 基价 × (目标库存 / 现库存)^0.55 × (1 + 传闻溢价)`;差价 > 35% 发商队;走在「山贼出没」的路上可能被劫 |

石津、碧石镇、风栈堡三个集市,货有粮、盐鱼、药草、碧石、铁器。玩家说「买 3 斗粮」「卖碧石」「看看行情」会变成 `trade`,verify 查钱、查货、查你在不在镇上。跟在商队旁边就是护送。

## 势力片段

| 部分 | 内容 |
|---|---|
| 变量 | `faction.{id}.power` · `faction.{id}.wealth` · `rep.{id}`(玩家声望)· `rel.{a}.{b}`(关系) |
| 类 | `faction` · `quest`(委托)· `rumor`(传闻) |
| ops | `new_quest` · `quest` · `rumor` · `spread` · `strike` |
| 规则(每 4 拍) | 守卫在警戒高时出城巡路;独眼虎劫道、有钱就招人、势大就夜袭碧石矿;公会挂剿匪悬赏和护送委托;碧石价太低矿工会罢工 |

**传闻**沿驿路、商队、走动的主角扩散(罗文从碧石镇走到石津,会把那边的传闻带过来),镇上听说了「北路有山贼」,从北路来的货就涨价。

**护送委托**:公会给往碧石镇的商队挂委托,商队在城门等你;你出城它跟上,被劫时你在车旁就能打退山贼,到货后拿赏金和声望。
