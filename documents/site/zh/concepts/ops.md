<!-- section: loop -->
## 一个回合

```text
提出(玩家一句话 / 角色的打算 / 规则 / hook)
   → 世界写叙事(要结果的事在叙事里调工具,引擎当场回答)
   → 写状态:<vars> 登记变量的新值 · <files> 文件系统的变化
   → 校验(工具和引擎的裁定优先;查 schema、范围、谁在场、类的增长策略)
   → 落地(写进世界文件夹)
   → 事件记进账本 → 订阅者、触发规则、界面
```

一拍之内每一步的细节见 [一回合怎么走](/docs/concepts/turn-flow)。

<!-- section: routing -->
## 每个 op 落在哪一边

op 由各个规则包登记,不是引擎写死的。下表是 `rpg` 包(石津镇)的 op;`pct` 包(灰橡宅)以 `rpg` 为底,另加 `san`(理智检定);`werewolf`、`monopoly` 有自己的 op(投票、出局、换阶段;掷骰、买地、结束回合)。

同一个 op 可能落在两边。判据不是 op 本身,而是**这一拍的叙事要不要等它的结果才写得下去**——要等,就是叙事里的工具;不用等,就写进叙事之后的状态。

| 去处 | op | 为什么 |
|---|---|---|
| **叙事里的工具**(写到这里停,拿到结果接着写) | `dice` · `roll` · `referee` | 成没成由骰子、裁判定 |
| | `need`(写作 `[ask 名字]`) | 她怎么说怎么做由她定 |
| | `combat` | 进战斗层:这一回合由战斗层结算,叙事按回答写 |
| | `new_town` | 引擎定路程和从哪个镇修路,叙事按路程写 |
| | `new_location`(这一拍就要走进去) | 引擎判画不画得进地图、挂在哪 |
| | `move_to` 玩家去远处(写作 `[move player …]`) | 引擎判到得了,还是被截在半路 |
| | `link` / `unlink`(这一拍要走这条路 / 路断挡道) | 断了会让镇上有地方走不到时引擎拒 |
| | 变量增减(写作 `[player.gold -12]`,钱可能不够时) | 不够就做不成 |
| | `[~map]` · `[~sheet]` | 只给玩家看,不等;落地后再画 |
| **状态 · `<vars>`**(闭 schema:写新值) | `set` · `add` · `flag` | 时间、位置(镇内)、钱、hp、警戒、flag |
| **状态 · `<files>`**(开 schema:文件系统) | `new` · `patch` · `remove` | 登记类的实例:物品、委托、状态效果、携带物 |
| | `new_npc` · `move_to` 玩家以外的人 | 新出现的人、别人的去向 |
| | `write` · `rm` · `edit` · `mkdir` · `rmdir` | 写下、改动、删掉的文字和文件 |
| | `new_location` / `new_town` / `link` / `unlink`(只是听说、提到) | 这一拍没走进去,叙事不等它 |
| | `define` | 世界需要一种还没有的东西(少见,单独校验) |
| **世界不写** | `mood` | 只给角色自己用;世界不写角色 |
| | `end_combat` | 战斗层自己用,结束战斗 |
| | `engage` | 已退役,默认关 |

`[options a | b | c]` 不是 op:它把下一步交给玩家,由引擎直接接住,不改世界。

<!-- section: refusal -->
## 拒绝

校验不通过时返回**可读的理由**,而不是静默失败:

```json
[{"op": "move_to", "who": "player", "to": "T004/tavern"},   // ✓
 {"op": "need", "who": "rowan"}]                            // ✗ 罗文不在这里 —— 只能问在场的人
```

可修的拒绝只把「写状态」退回重写,叙事不改;重写后仍不通过的就丢掉,通过的照常落地。`add` 超出范围会被钳位;只读变量只有引擎能写;关掉一个 op 就是把它从 `actions` 表里拿掉。

<!-- section: hooks -->
## 订阅也只能提出

订阅者(hook)在事件落地之后被调用,但它**不能直接写文件**,只能把一个 op 排进队列(`sdk.enqueue`),下一回合照样过校验。这样引擎之外的逻辑也绕不过「只有世界能改世界」。

<!-- section: tiers -->
## 谁花 token

- 和你在同一地点的角色:每人一次 LLM 调用,并行。
- 不在身边的角色:在自己所在的地方走一拍,同样走校验。
- 经济、势力、状态效果倒计时这类后台单元:纯代码,不花 token,只能写自己声明过的变量。

三者的提出走同一套校验。
