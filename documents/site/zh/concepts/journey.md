## 这一页讲什么

这一页按真实顺序走一遍:你装好软件、接上模型、挑一个世界、说第一句话、玩到存档、再自己做一个世界发出去。每一步只讲**发生了什么、你会看到什么**;细节链到各自的页面。

先记住三件事,后面每一步都建立在它们上面:

1. **世界、角色、玩家是三方。** 世界(主持)决定后果,角色有自己的记忆和意图,玩家的话是**一次尝试**,不是事实。
2. **模板是做世界的单位。** 一个模板 = 世界 + 角色的链接 + 规则包 + 玩法合约 + 编排。你玩的每一局都从一个模板开出来。
3. **每回合落一次「世界提交」。** 状态都在文件里,一回合一个提交;回退就是从某个提交另开一条线。

<!-- section: editions -->
## 两种引擎:完整版和开源版

| | 怎么装 | 一回合 |
|---|---|---|
| **完整版** | `pip install worldlines` / `pip install neonrp`(PyPI) | 两拍:先**商量**,再**清算** |
| **开源版** | 从 [GitHub 仓库](https://github.com/LudicDynamics/WorldLines) 源码安装 | 只有清算这一拍 |

两种都读同一套模板、存档和规则。模板写了两拍、但你跑的是开源版时,引擎会退回单拍,角色照常行动。下面按完整版讲。

<!-- section: install -->
## 1. 安装和启动

- `worldlines`:打开本机网页 `http://127.0.0.1:8787/local`(本地 Hub、游玩页、工作台)。
- `neonrp`:打开终端里的启动器,挑世界、开局、玩,全在终端。
- 两个命令共用 `~/.worldlines`(模板、角色库、存档),在网页里开的局终端里也接得上。
- 启动时检查新版,默认自动更新并重启;想先问一声:`/update mode prompt`。
- 不想装:在 [worldlines.gg](https://worldlines.gg) 或 iOS App 直接玩。

本机自带两个世界:**灰橡宅 · 关上的门**(一夜推理,适合第一次)和 **石津镇 · 雾退之夜**(开放小镇)。其他官方世界在本地 Hub 里不登录也看得到,登录后可以下载到本机。

<!-- section: model -->
## 2. 接上模型

- **Worldlines 账号**:终端里 `/login`,网页里点登录。登录后用我们中转的模型,并打开判官 **Jev**。
- **自己的 key**:OpenCode、DeepSeek、OpenRouter、Anthropic、OpenAI、GLM,或任何 OpenAI 兼容端点。
- 新开的局用你选过的模型;没选过且已登录就用 Worldlines;否则用第一个有 key 的。

**判官**只回答很小的是非题,比如「这段商量谈妥了没有」「这个名字指的是谁」。没有 Jev 时,这些题由**这一局自己的模型**来答(每拍多几秒);再没有就用确定的规则兜底。判官从不写故事。

详见 [接模型](/docs/players/providers)。

<!-- section: start -->
## 3. 开一局

你选模板、(可选)捏自己的角色、点开局。引擎这时做:

1. 在 `~/.worldlines/plays/` 下建一个新目录,这一局的所有东西都在里面。
2. 把模板的世界、你选的语言层、规则包装进去。
3. **角色这时才实体化。** 模板里的角色大多是到角色库的链接;开局时才复制成这一局里的角色,带上自己的记忆。同一个角色可以同时活在好几个世界里,互不影响。
4. 合并设置:规则包 < 玩法合约 < 编排 < 世界 < 这一局。后面的覆盖前面的。
5. 播开场(有开场图先播),主持写出作者定的第一幕。

<!-- section: turn -->
## 4. 一回合:先商量,再清算

你说一句话,回合开始。

**商量拍。** 主持把你的话放进场景,把话筒递给在场的角色;角色接话、提条件、讨价还价。主持会把这件事要花的钱、要过的检定、要花的时间列出来。**这一拍世界不动**:时钟不走,东西不变,你可以接着说、改主意。

什么时候从商量转到清算:

- 判官判断「谈妥了」(没有 Jev 就由这一局的模型判断);
- 你直接说「定」「就这么办」;
- 一句没什么可谈的话(比如在城里走两步)直接清算;
- 外面的事不等你们谈完。

`@dm` 叫主持果断接一轮;`@名字` 把话筒交给那个角色。

**清算拍。** 谈定的事真正发生:

1. **谁动。** 判官预判你想做什么、哪些角色会跟着动;在场的角色各自决定自己做什么,不在场的角色在别处也走一步。
2. **规则先判。** 需要掷骰的掷骰,需要进入战斗之类的规则层就进入。
3. **写叙述。** 主持写这一拍的正文。凡是结果会影响下文的事,正文里调用一次工具,引擎当场给出裁定,主持照裁定往下写。谈定的花费由引擎直接从钱包结算。
4. **写状态。** 另一次干净的调用读完正文,写出变化:登记过的数值(钱、体力、时间……)和世界里的文件(谁去了哪、拿到了什么)。
5. **校验。** 引擎逐层查:写法对不对、名字和变量存不存在、世界规则允不允许。不对就只让状态重写,正文不变。
6. **落地。** 改动写进文件,回合数 +1,生成这一回合的世界提交。

**状态先快后准。** 第 4 步先用快的方式落下,你马上能接着玩;同时一个会思考的慢版本在后台重读这一拍,几秒后把写错的值改过来(最多等 90 秒)。界面上会看到「复核中」,然后是「修正了什么」或「没变」。你先说了下一句,复核就取消。

<!-- section: save -->
## 5. 存档、回退、回放

- 一局就是一个目录,一回合一个提交。网页上能看到提交图。
- **回退不删东西**:回到某一回合,是从那里另开一条线,原来那条线还在。终端:`/undo list` 看,`/undo <回合>` 回去。
- `/save`、`/load` 存读;`/open` 接着玩或开新局。
- 玩到结局(或手动)可以导出成**回放**:故事、时间线、封面,分享给别人看。

详见 [存档 · 分支 · 撤销](/docs/players/saves)。

<!-- section: create -->
## 6. 做自己的世界

三条路,改的都是同一个模板文件夹:

- **网页创作台 / iOS**:从官方模板出发,加角色、剧情、结局、线索,写四种语言的标题和简介,换封面。编排只能在 2–3 套预设里选,图是只读的。
- **本机工作台**:「＋ 新建 Template / 世界 / 角色」,能改编排图、地图、触发器,改完写回模板。
- **coding agent**:用 Claude Code 或 Codex 打开模板文件夹。每个模板都带 `AGENTS.md`、`CLAUDE.md` 和 `spec/`,照着规范写文件夹和 JSON / Markdown,不用改引擎。

角色放在角色库(`~/.worldlines/souls/`),模板里只写链接。

详见 [创作者快速开始](/docs/creators/quickstart)。

<!-- section: lint -->
## 7. 检查(lint)

`neonrp template lint <模板>` 或工作台里的检查,会先把模板开成一局放在临时目录,再查引用、角色、剧情、素材、合约、四种语言。结果分两级:**block** 挡发布,**warn** 只提醒。

<!-- section: publish -->
## 8. 发布到 Hub

| | 怎么上 | 谁能看到 |
|---|---|---|
| **自由区** | 本机创作台直接上传,自动检查通过就公开 | 所有人;事后管理 |
| **默认区** | 网页 / iOS 创作台提交,进审核 | 审核通过后上架 |

上传前三道门:包里不能有密钥或凭据文件;lint 没有 block;四种语言的标题和简介齐全、有封面。同一个作品再提交是出新版本:审核中再提交会顶掉排队的那版;已上架的改版在审核通过前,线上照旧是旧版。
