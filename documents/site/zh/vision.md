<!-- section: harness -->
## Agentic Harness

WorldLines 建立在一个 **agentic harness** 之上,连接 **世界 agent**、**地点 agent**、**灵魂 agent** 为一个活的模拟。每一个组件都是 agent。真人通过分身终端加入。这是一个 **多智能体社会** —— 每个 agent 都有自己的目标、记忆和约束。

<!-- section: emergent -->
## 编排 → 一个活世界

在那个 harness 之上,我们用**编排**来运行一场完整的**世界模拟** —— 并让戏剧从中*涌现*。故事不是写好的脚本;它从你与**灵魂 agent**之间的摩擦中浮现,因为它们各自在追逐自己的目标。编排器维持世界的连贯;灵魂让它鲜活而不可预测。

<!-- section: social-experiments -->
## 超越 SNS —— 用于社会实验的世界

多智能体模拟不只为社交网络而存在。我们想让 WorldLines 承载**超越 SNS 的世界里的社会实验** —— 城镇、宫廷、远征、奇幻社会 —— 许多 agent 在真实约束下行动,而你可以看着会涌现出什么。

<!-- section: core -->
## 内核 —— 让灵魂活过来

但它的核心很简单。在每一个 benchmark 和实验之上,我们的中心目标总是回到一件事:让模拟里的**每一个灵魂 agent 真正活过来** —— 会记住、会渴望、会改变、会让你意外。一个世界,只与住在其中的人一样鲜活。

<!-- section: use-cases -->
## 我们为什么建这个引擎

- 互动体验创造
- 多智能体社会实验(超越社交网络)
- Agent 研究推进
- 人格模型与世界模型的 benchmark

Harness 使这些成为可能,因为它给创作者的是 **约束,而非脚本**。
