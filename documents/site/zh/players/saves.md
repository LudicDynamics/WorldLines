## 自动保存

每一局都是 `~/.worldlines/plays/` 里的一个文件夹,每一回合落定后自动保存,不用手动存。关掉再打开,接着玩就行。

<!-- section: web -->
## 在网页上

在「游玩一览」里点那个世界,拉出的卡片里有「存档」列表:

- **继续**:接着玩这一局;
- **新开一局**:同一个世界从头开始,原来那局留在存档里;
- **删**:删掉这一局(会再问一次)。

撤销和回到某一回合目前只能在终端里做。网页和终端用的是同一份存档:在网页上玩的局,终端里 `/load` 也能接着玩。

<!-- section: cmds -->
## 在终端里

| 命令 | 作用 |
|---|---|
| `/open` | 列出能玩的世界和存档;`/open <存档>` 接着玩,`/open <世界>` 开一局新的 |
| `/load` | 选一个存档接着玩,或者读本局里存过的快照 |
| `/save [名字]` | 在本局里存一个快照 |
| `/undo` | 退回上一步 |
| `/redo` | 把刚退掉的那一步做回来 |
| `/undo list` | 列出这条线上的回合 |
| `/undo <回合>` | 回到那一回合,从那里另起一条新线;原来那条线保留 |

另起的线不会改动原来那条,原来那条的每一回合都还在。

<!-- section: under -->
## 背后是提交图

每个回合都是一次提交(commit),一局就是一张提交图,见[世界线](/docs/concepts/worldlines)。在终端外看:进到那一局的文件夹,`neonrp commit log`。
