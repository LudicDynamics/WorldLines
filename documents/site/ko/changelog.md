## v0.4.0 — 하나의 엔진, 두 개의 제품 (2026-08)

- **엔진 / 셸 분리** — Web UI와 데스크톱 셸을 오픈소스 [WorldLines 저장소](https://github.com/LudicDynamics/WorldLines)(AGPL-3.0)로 이관; 엔진은 초경량 시뮬레이션 코어로 수렴(`pip install worldlines` 사용법은 그대로)
- **누가 말할지는 에이전트가 결정** — world-agent가 장면을 주재: 반응해야 할 캐릭터만 깨우고, 답이 필요하면 직접 묻고, 캐릭터도 세계가 알아야 할 일은 손을 들어 알림
- **캐스트로의 직통선** — 턴 밖에서 `@이름` 일대일, `#` 로 장면 전체에; 캐릭터 자신의 기억으로 답하며 세계 시계는 흐르지 않음
- **관찰이 독립된 화면으로** — 관찰 페이지는 3패널 채널 글라스: 채널 목록(◉세계 / #여기 / @캐릭터), 라이브 피드, 재장 레일
- **재장 하트비트** — 호명되지 않은 재장 캐릭터도 매 턴 가벼운 반응을 보여 군상이 얼지 않음
- **주사위와 물리 검증 이동** — `roll_check`(BRP d100 / SRD d20)가 체인에; 모든 이동은 맵 검증 통과
- **모드는 둘뿐** — `orchestrator` 와 `multi-agent`; 구 `fast` 모드 은퇴, 옛 세이브는 조용히 이행
- **수정** — 멈춘 LLM 스트림은 타임아웃 후 재시도 사다리로; 세션은 새로고침 시 자가 복구; 긴 생성이 잘리지 않음

## v0.2.10–v0.3.0 — LocalShell: 엔진이 완전한 로컬 제품으로 (2026-07)

- **LocalShell** — `neonrp web` 가 플레이 화면에서 완전한 로컬 제품으로: 게임 파사드 / 서재(이어하기·세계 라이브러리) / 창작 게이트 / PrePlay 확인 / 플레이 툴바; 데스크톱 셸과 동일 빌드
- **준비 워크벤치** — 스튜디오 + 3 캔버스(세계/캐릭터/각본): AI가 초안을 쓰고 결과를 실제 파일로 반영
- **엔진 방어선 3종** — 깨진 JSON은 쓰기 경계에서 복구 또는 거부; `neonrp validate` 는 플레이 가능성 검진으로; 위치 심판(마을 안 자유, 마을 간은 성문 경유, 순간이동 불가)
- **턴 롤백** — 과거 턴에서 git 식 분기, 현재 라인 유지
- **임포트가 완전한 soul로** — SillyTavern 카드를 LLM이 완전한 soul로 보완; 생성 인터뷰의 AI 사고를 실시간 표시
- **안정성** — CJK 세계 이름 전면 수정; Playwright e2e 기반 + 릴리스 게이트(테스트 통과 없이는 배포 없음)

## v0.2.4–v0.2.9 — 창작·세계·살아있는 이동 (2026-06)

- **생성한 세계가 진짜 멀티에이전트 세계로** — 완전 초기화, 캐릭터별 soul-agent, 보유 세계 라이브러리(`worlds/` 와 `plays/` 분리, 열람+삭제)
- **더 풍부한 웹 플레이** — 월드 맵 + 마을 맵(줌·핀치·최소화), 오케스트레이션 진행, 소울 심상 패널, 이어하기 & 리플레이
- **저작** — 엔티티를 중첩 하위 폴더에(`game/<kind>/.../<id>.json`)
- **살아있는 이동(trial-beta)** — 각 소울의 행선지는 world-agent가 결정하여 상태와 서술이 어긋나지 않음;캐릭터가 마을 사이를 순간이동하지 않음
- **안정성** — CJK/IME 입력 수정, 설치 방식별 자동 업데이트, 더 빠른 업데이트 감지, Windows 설치 직후 같은 셸에서 실행
