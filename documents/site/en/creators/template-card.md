## The folder

> **Status: ships with 1.0** — the full field table and every lint code are in `spec/template.md` inside the template folder.

A template is a folder named `<id>.template/`. Stoneford looks like this:

```text
stoneford-town.template/
  template.json          ← entry point: this page is about it
  world-overlay/         ← changes laid over the built-in world (map, places, economy data…)
  prompts/               ← the prompt layer (world rules, voice, entries)
  plots/P20/plot.json    ← plot pack: stages, triggers, endings
  orchestration.json     ← orchestration graph patch (written by the orchestration bench)
  i18n/<lang>/           ← English / Japanese / Korean translation layers
  assets/                ← cover, ending CGs and other pictures
  AGENTS.md  CLAUDE.md  spec/   ← notes and specs for coding agents (generated by the engine)
```

Greyoak House doesn't borrow a built-in world; its whole world sits in the template's `world/`.

## Stoneford's template.json (excerpt)

```json
{
  "schema": "worldlines.template/1",
  "id": "stoneford-town",
  "version": "0.1",
  "zone": "reviewed",
  "forkable": true,
  "card": {"title": "石津镇 · 雾退之夜", "pitch": "一年只有一夜,雾会从北路上退开……",
           "cover": "assets/cover.png", "lang": "zh", "tags": ["奇幻", "雾", "小镇"]},
  "mode": {"ending": "multi", "freedom": "semi"},
  "play_contract": "open-adventure@1",
  "world": {"builtin": "stoneford-elena", "prompts": "replace", "overlay": "world-overlay"},
  "uses": {"template": "two_beat", "version": "1.0", "soul": "S-judge"},
  "pack": {"name": "rpg", "mixins": ["economy"], "engine": {"turn": {"mode": "v3"}}},
  "souls": [{"sid": "elena", "role": "npc"}, {"sid": "rowan", "role": "npc"}],
  "prompts": ["prompts/world.json", "prompts/voice.md", "prompts/town.json"],
  "plots": ["plots/P20"],
  "lint": {"level": "draft"},
  "orchestration": "orchestration.json",
  "creation": {"add": ["soul", "plot", "ending", "clue", "rule"], "…": "…"},
  "audio": {"theme": "emberglass", "ambient": "fireplace"},
  "rewards": [{"id": "old_fog_map", "kind": "card", "rarity": "common", "when": "flag:has_map", "title": {"en": "The Old Fog Map", "…": "…"}}]
}
```

The base card is in Chinese; the English card ("Stoneford · The Night the Fog Withdraws") lives in `i18n/en/template.json`.

<!-- section: fields -->
## Fields

| Field | What it holds |
|---|---|
| `card` | The card: `title`, `pitch` (one line), `cover` (an image inside the template), `lang`, `tags`. Cards in other languages go in `i18n/<lang>/template.json` |
| `mode` | `ending`: `open` (no ending) · `single` (one ending) · `multi` (several endings); `freedom`: `free` · `semi` · `guided` (how far the player may roam) |
| `zone` | `reviewed` = Default Zone, `open` = Free Zone; unset counts as Free Zone. See [Publish to the Hub](/docs/creators/publish) |
| `forkable` | `true` = this Default Zone world offers "Make a copy". Your own works can always be copied; no need to set it |
| `play_contract` | Which experience it promises, e.g. `mystery-trpg@1`, `open-adventure@1`. See [Play contracts](/docs/creators/contracts) |
| `world` | Where the world comes from: `path` (a folder in the template) or `builtin` (a world built into the engine); `overlay` lays changes over it; `prompts: "replace"` = the template's prompt layer replaces the world's own |
| `uses` | Which orchestration this world runs (how a turn moves): `template` is the orchestration's name, `soul` how the characters present act, `params` picks parameters (e.g. `{"pace": "quick"}`). See the next section |
| `pack` | The rules pack: `name` is one of `rpg` · `pct` · `werewolf` · `monopoly`; `mixins` adds fragments (`economy` · `factions`); `engine` goes into the run's engine settings |
| `souls` | The cast. See [Character library and casting](/docs/creators/characters) |
| `prompts` | Prompt-layer files |
| `plots` | Plot-pack folders. See [Plot packs](/docs/creators/plot-packs) |
| `lint` | `level: "draft"` makes missing pictures and an over-budget token count warnings; unset or `"publish"` blocks them. See [Lint](/docs/creators/lint) |
| `ui` | Asset slots `slots`, views `views`, named image prompts `prompts`, per-turn token budget `budget`. See [Assets](/docs/creators/assets) |
| `opening` | `cg`: pictures shown in order at the start, each with `image` and `caption` |
| `audio` | Music and ambience: `theme`, `ambient`, overridable per place (`places`) |
| `rewards` | Reward cards, handed to the player when `when` holds (not in the Free Zone) |
| `creation` | What a creation desk may **add** to this template: `add` (characters, plots, endings, clues, rules), the trigger kinds allowed in `triggers`, how characters are collected in `collect`. Unset = nothing is open |
| `orchestration` | The graph patch file written by the orchestration bench |
| `models` | `play` names the run's default model, written as `provider/model` |

<!-- section: uses -->
## `uses`: how a turn moves

`uses` picks the **orchestration**; it has nothing to do with the content. Both built-in templates say `"template": "two_beat"`: a turn has a planning beat and a resolve beat (see [Planning and resolve](/docs/concepts/planning-resolve)).

- The `worldlines` / `neonrp` packages on PyPI include the full two-beat orchestration.
- An engine built from the open-source repository has the single-beat turn (`one_beat`) only. A template that says `two_beat` still plays there: it falls back to the single beat and keeps the characters' way of acting the template named.

The web Hub and iOS desks only let you pick one of a few orchestrations, shown as a read-only graph; only the local orchestration bench edits the graph.

<!-- section: mixins -->
## Rules packs and fragments

`pack.name` picks the play rules; `pack.mixins` adds system fragments. Four rules packs are built in: `rpg` (d20), `pct` (percentile investigation), `werewolf`, `monopoly`; two fragments: `economy` (markets, prices, caravans) and `factions` (factions, rumors, quests). See [Fragments](/docs/creators/fragments).

## Change a template

Built-in templates are read-only. Copy one first:

```bash
neonrp template fork stoneford-town my-town --store ~/.worldlines/templates
neonrp template lint ~/.worldlines/templates/my-town.template
```

Or press "Make a copy" on the Template page of the local creation desk.
