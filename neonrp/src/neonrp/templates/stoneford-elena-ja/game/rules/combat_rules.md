# 戦闘規則（MVP）

## 1. ターンの流れ
1) 先攻：双方が各々 d20 + Dex を振る。高いほうが先に行動する。同値ならプレイヤー優先。
2) 行動：1ターンにつき主要行動を1回（攻撃／スキル／道具の使用／防御／逃走の試み）。
3) 決算：持続状態（出血／中毒など）はターン末に決算する。

## 2. 命中とダメージ（基礎）
- 命中判定：d20 + 攻撃加算値 >= 目標の防御（DEF）で命中
- 攻撃加算値：近接=STR修正；遠隔=DEX修正；呪文=INT修正（拡張可）
- ダメージ：武器の基礎ダメージ + 能力修正 + d6
- 防御（DEF）：10 + 防具DEF + VIT修正（MVP）

## 3. 状態（MVP）
- 出血：ターン末 -2 HP（回数を重ねられる）
- 中毒：ターン末 -1 HP、3ターン持続
- 気絶：次のターン、主要行動を飛ばす

## 4. 逃走
- 逃走判定：d20 + Dex >= 12 + 敵の危険度（または敵のDex修正）
- 成功：戦闘から離脱し、戦闘前の位置に戻る。失敗：このターンの行動を無駄にする。
