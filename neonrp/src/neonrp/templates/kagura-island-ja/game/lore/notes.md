# 神楽島 — 世界観察ノート / 噂 (append-only)

- 離島は引き潮のときのみ徒渉で到達できる(早朝〜午前)。
- 神社本殿は夜間立ち入り禁止(禁忌1:島民信頼-15, 宮司信頼-20)。
- 単独で火口へ向かうと直ちに危険事件が発火する(禁忌4)。
- 鏡子さんは白髪の者に反応する(和渊の血脈、信頼 +5);勾玉を見ると動揺する(+15)。
- 悠人の研究ノートは博物館の奥、棚の裏に隠されている(67回のループの記録)。
- 白の壁の刻み文字は離島の船着き場にあり、ループごとに一行増える——物理的痕跡は持続する。
- 真琴先生は見た目が12年変わらない、微笑むが目は笑っていない(Yith 完全寄宿)。
- 翼は離島の岩棚の茂みの陰に隠れており、発見成功で 血痕→小道→岩棚 と辿れる。
