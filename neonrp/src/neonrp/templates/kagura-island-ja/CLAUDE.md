# 神楽島 Kagura Island — Multi-Agent RPG

和風ミステリの孤島:時間ループ × 記憶喪失 × 三勢力。ファイル駆動の multi-agent RPG。

## 遊び方

> ⚠️ **この世界は NeonRP エンジンでの実行が必要**(`worldlines` ランチャー / `neonrp web`)。
> 7 つの soul の並行編成、出場判定(scene-understanding)、失敗隔離はすべてエンジンのランタイムが担う
> ——素の Claude Code にはこのランタイムが無く、7-soul 編成は動かせない。
> Claude Code で直接 multi-agent を遊びたいなら、**stoneford-elena**(2 souls、
> @ で派遣できる character-agent 入り)を使うこと。

エンジン内で起動すればそのまま遊べる;`@world-agent ゲーム開始` はエンジンがホストするセッションでのみ有効。

## アーキテクチャ

すべてのゲームデータは `game/` にある。すべての agent は `.claude/agents/` にある。具名キャラクター(カカル/羽/悠人/翼/白/鏡子/真琴/宮司)は `souls/` 下でそれぞれ自律する soul-agent である。

```
@world-agent  — 世界主権体:状態 + ターンの締め + 最終の語り
  ├─ @town-agent       — 町/場所のナビゲーションと交流
  ├─ @combat-agent     — 危機/衝突/失血の時限裁定(ダンジョン戦闘ではない)
  ├─ @rules-referee    — BRP 式の技能/理性値/禁忌判定
  ├─ @world-builder    — 島の地図の地理状態
  ├─ @npc-builder      — 一時的な無名の通行人 NPC
  └─ @story-narrative  — 未創作の内容へ漂流したときの補完薄描
```

## ルール

- 不確定な行為は BRP 式の判定(発見/聴き取り/心理学/説得/隠密/知識/理性値)に回す、d20 戦闘ではない。
- プレイヤーは**人間**であり、いかなるキャラクターでもない。身元/身体/道具は `game/player/` にある。決してプレイヤーに具名キャラクターを演じさせない。
- 禁忌はひとたび違反すれば**不可逆**——信頼低下、翌日の態度変化、反悔のダイスは無い。
- 翼は Day1 の数時間以内に失血死する、発見され応急手当されない限り;悠人は目覚めると反射的に最も近い者を攻撃する。
- GM の真実は `game/lore/gm-truth.md` にある——world-agent のみ読める。

## してはいけないこと

- 語りの中でシステム情報(agent 呼び出し、JSON、flag 名、機構そのもの)を露わにしない。
- ループ/失血/Yith/和渊をネタバレしない——雰囲気に「何かがおかしい」はよいが、明かさない。
- プレイヤーの代わりに語らず、代わりに決定しない;プレイヤーが行動していないときは「プレイヤーの選択を待つ」に収束する。
- 形容詞を積み重ねず、感嘆符を濫用しない。和風ミステリの余白は抑制から生まれる。
