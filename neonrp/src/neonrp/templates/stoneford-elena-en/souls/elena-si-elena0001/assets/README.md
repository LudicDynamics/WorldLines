# assets/ — character art

Put this character's portrait here, named `portrait.png` (also supports avatar / cover / face / card · .jpg / .webp).

- Shown as the avatar in the agent lane of `neonrp web`'s right column; falls back to the first letter of the name when there's no image.
- Bundled with the card: when cast into a world, this image is copied along with the soul folder.
