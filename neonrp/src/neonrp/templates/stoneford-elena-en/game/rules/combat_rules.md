# Combat Rules (MVP)

## 1. Turn Flow
1) Initiative: both sides roll d20 + Dex. The higher acts first; on a tie, the player goes first.
2) Action: one main action per turn (attack / skill / use item / defend / flee attempt).
3) Resolution: ongoing statuses (bleed / poison, etc.) resolve at the end of the turn.

## 2. Hit and Damage (basic)
- Hit check: d20 + attack bonus >= target's defense (DEF) is a hit
- Attack bonus: melee = STR modifier; ranged = DEX modifier; spell = INT modifier (extensible)
- Damage: weapon base damage + attribute modifier + d6
- Defense (DEF): 10 + armor DEF + VIT modifier (MVP)

## 3. Statuses (MVP)
- Bleed: -2 HP at end of turn (stacks by count)
- Poison: -1 HP at end of turn, lasts 3 turns
- Stun: skip the main action next turn

## 4. Fleeing
- Flee check: d20 + Dex >= 12 + enemy danger level (or enemy Dex modifier)
- Success: break off combat, return to the pre-combat position; failure: the action is wasted this turn.
