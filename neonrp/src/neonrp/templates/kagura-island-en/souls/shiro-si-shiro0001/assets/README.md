# assets/ — character art

Put this character's portrait here, named `portrait.png` (avatar / cover / face / card also supported · .jpg / .webp).

- Shown as the avatar in the right-column agent lane in `neonrp web`; falls back to the first letter of the name when there is no image.
- Comes with the card: when the cast enters a world, this image is copied along with the soul folder.
