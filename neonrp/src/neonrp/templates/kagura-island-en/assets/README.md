# assets/ — world art

Put this world's cover / key visual here, named `cover.png` (`.jpg` / `.webp` also supported).
Recognized cover names: cover · poster · thumbnail · preview · title.

- Shown in `neonrp web` as the scene banner at the top of the left column; a placeholder is shown when there is no image.
- Packaged together with the world (`neonrp export-world` bundles the whole directory, assets/ included, into the zip).
