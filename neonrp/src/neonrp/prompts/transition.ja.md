# ルールパック自身の操作
フェーズの切り替え・投票・脱落・売買のようなルールパック自身のことは、上の ops の書き方で <files> に一行ずつ書く。**変数としては書かない**。変数表で「… op で変える」とある変数は <vars> に書かず、その op で書く:
{pack_ops}

## ここでは状態遷移だけを行う:この拍で世界の何が何に変わったか。二つに分けて出力する:
<vars>
登録された変数の新しい値。一行に一つ「変数名 = 新しい値」、この拍で変わったものだけ;変数名は上の「変更できる変数」にあるものだけを使う;プレイヤーの位置は location に書く(場所が変わったら必ず書く。語りがそこの人や物しか描いていなくても):叙述が最後に止まった場所——道の途中や、門の前でまだ入っていないなら、その道(「遠出」に道ごとの id がある)、目的地ではない
</vars>
<files>
そのほかファイルシステムに残る変化。一行に一つ、上の ops の書き方で:
- new / patch / remove:登録されたクラスのインスタンス(アイテム、依頼、状態効果、所持品……);引き受けた・終えた・放棄した依頼は、その依頼そのものを patch する(状態、誰が引き受けたか)
- new_npc:語りに新しく現れた人
- move 誰 行き先:プレイヤー以外の人の行き先
- 書き残された文字:[~write パス.md]文字の原文[/write](パスは .md / .txt / .json のみ);消すとき:rm パス;ほかに edit / mkdir / rmdir
- new_location / new_town / link / unlink:聞いただけ・話に出ただけで、この拍では入っていない場所と道——地図にない場所を聞いたら、場所として落とす:別の町・村・港は new_town、町の中の場所は new_location。誰かの属性に書くだけにしない
- define:世界にまだない種類のものが必要なとき(まれ)
</files>
語りで起きたことはすべて入れる;ツールの返答でエンジンがすでに判定したものは、返答のとおりにする;起きていないことは書かない;物も落とす:誰かが使った・食べた・食べさせた・渡した・落とした物は、残りの数を patch(一つも残らなければ remove)、手に入れた物は new;お金も同じ:払った・受け取ったお金はお金の変数に書く;人や動物に名前をつけたら、その名前を patch;プレイヤーも(角色)の印がついたキャラクターも同じように書く(負傷・物・装備)。ただしキャラクターの感情・考え・つもりは書かない。<lines> と <options> はもう書かない。
体に出た結果は数字で落とす。語りに書くだけではだめ:怪我・毒・吐き気・凍え・疲労——その場の損失は変数(例 player.hp);続くものは状態にする(資料に状態のクラスがあれば):状態表にあるものは `new status 名前` だけ、どれだけ続きどう治るかは表のその行が決める;表にないものは `new status 名前 note=一行のルール`、書き方は自由(例「3ターン続く · 毎回 player.hp -1 · 薬で治る」)。語りで状態が治ったら(薬を塗った、火にあたった、眠った)remove する。手配・嫌疑・評判・知ったことは体の状態ではない:flag・変数・関係に書く。判定に失敗し、前もって失敗の代償を決めていたなら、その代償は必ず落とす。
誰のものかを書く:状態や持ち物は誰かのもの——名前の前に持ち主を書く、`{{{{<id>}}}}/名前`。`{{{{user}}}}` はプレイヤー;ほかの人は資料で名前の前にある id を {{{{ }}}} で囲んで書く;例 `new status {{{{user}}}}/打ち身 note=…`、`remove {{{{<id>}}}}/出血`。場所はフルパスで(例 `T001/guild`)。文(note・書き残す文)の中で人に触れるときも `{{{{id}}}}` と書く。エンジンが名前に戻す。名前だけならプレイヤーのもの。
