# Dark Train — 暗夜列车

一辆永不停站的列车在没有风景的灰色里前行。你在第 6 节车厢醒来，
忘了自己是谁。前面还有五节车厢和一节连接走道，每节都把记忆收走一点。
没有人告诉你目的地。窗外只有雾，不动的、概念性的雾。

**Genre**: Quiet cosmic horror · Lovecraftian puzzle · 沙盒跑团（BRP）

**Rules**: BRP — *Basic Roleplaying: Universal Game Engine*（Chaosium，ORC License）+ 本世界自有规则（禁知 / 付代价再试 / 记忆碎片）。
**Setting content**: CC-BY-4.0。

## 你扮演

一名乘客——但你已经不记得自己为什么上了这趟车。
醒来时身上有一节断票根（"6 → 1"清晰可读，目的地被涂去）和一片金属
钥匙残片。无名、无证件、无电话。你的左无名指上有戒痕，戒指不在任何
口袋里。

## 怎么玩

旧格式(模板之前的 orchestrator 世界)。玩的时候会写进文件夹,先复制一份:

```bash
cp -R worldlines/examples/worlds/dark-train /tmp/dark-train && cd /tmp/dark-train
neonrp tui --play
```

## 流程提示

- 每回合先看 HUD 行（车厢号 / HP / SAN / tick / 碎片数）
- 你的所有意图都允许尝试——荒诞或过分的会路由到判定，世界用一致的结果回答
- 检定全部 d100：1d100 ≤ 技能 = 成功；≤ 技能 / 5 = special；≤ 技能 / 20 = critical；99/00 = fumble
- 难度：Easy ×2 / Average / Difficult ×½
- 理智检定 d100 对当前 SAN：成功损失少，失败损失多；一拍之内失去当时 SAN 的一半 → 临时疯狂
- 普通失败可以「付代价再试」一次：先说出你愿意付的具体代价
- 越理解这列车（禁知），最大 SAN 越低

## 设计承诺

> 你永远不会赢得一场干净的胜利。每个谜题的解答都要付代价。
> 每个找回的真相，同时也是某个失去的东西。
