# 전투 규칙(MVP)

## 1. 라운드 진행
1) 선제: 양측이 각각 d20 + Dex를 굴린다. 높은 쪽이 먼저 움직이고, 같으면 플레이어가 먼저다.
2) 행동: 라운드마다 주 행동 1회(공격 / 기술 / 아이템 사용 / 방어 / 도주 시도).
3) 정산: 지속 상태(출혈, 중독 등)는 라운드 끝에 정산한다.

## 2. 명중과 피해(기본)
- 명중 판정: d20 + 공격 보정 >= 대상의 방어(DEF)이면 명중
- 공격 보정: 근접 = STR 보정, 원거리 = DEX 보정, 주문 = INT 보정(확장 가능)
- 피해: 무기 기본 피해 + 능력치 보정 + d6
- 방어(DEF): 10 + 갑옷 DEF + VIT 보정(MVP)

## 3. 상태(MVP)
- 출혈: 라운드 끝에 HP -2(여러 번 겹칠 수 있음)
- 중독: 라운드 끝에 HP -1, 3라운드 지속
- 기절: 다음 라운드의 주 행동을 건너뛴다

## 4. 도주
- 도주 판정: d20 + Dex >= 12 + 적의 위험 등급(또는 적의 Dex 보정)
- 성공: 전투에서 벗어나 전투 전 위치로 돌아간다. 실패: 이번 라운드 행동을 허비한다.
