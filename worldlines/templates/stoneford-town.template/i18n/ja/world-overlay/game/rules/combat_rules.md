# 戦闘ルール(MVP)

## 1. ターンの流れ
1) 先攻:双方がそれぞれ d20 + Dex を振る。高いほうが先に行動する。同値ならプレイヤーが優先。
2) 行動:1 ターンにつき主要行動 1 回(攻撃/スキル/アイテム使用/防御/逃走の試み)。
3) 処理:持続する状態(出血/毒など)はターン終了時に処理する。

## 2. 命中とダメージ(基本)
- 命中判定:d20 + 攻撃ボーナス >= 目標の防御(DEF)なら命中
- 攻撃ボーナス:近接=STR修正、遠隔=DEX修正、呪文=INT修正(拡張可)
- ダメージ:武器の基本ダメージ + 能力値の修正 + d6
- 防御(DEF):10 + 防具DEF + VIT修正(MVP)

## 3. 状態(MVP)
- 出血:ターン終了時に -2 HP(回数は重ねがけ可)
- 毒:ターン終了時に -1 HP、3 ターン持続
- 気絶:次のターンの主要行動を飛ばす

## 4. 逃走
- 逃走判定:d20 + Dex >= 12 + 敵の危険度(または敵の Dex 修正)
- 成功:戦闘を離脱し、戦闘前の位置に戻る。失敗:このターンの行動を失う。
