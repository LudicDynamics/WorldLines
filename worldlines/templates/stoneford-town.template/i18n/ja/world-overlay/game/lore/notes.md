# ストーンフォード・エレナ — 世界観察ノート

- ストーンフォードは新しく来た冒険者に愛想がいいわけではないが、勘定を払い約束を守る者のことは覚えている。
- ジェイドストーンには才能を持て余した若い冒険者ローワンがいて、北境の「世界の果て」の伝説を追っている:そこには底の知れない洞穴があり、出どころの知れない宝具や不思議な道具を絶えず吐き出しているという。
- モスバロウの地下墓所はまだそこにあるが、このデモの最初の一拍の要は、町に腰を据えることと、heroine が最初に人の輪へ入っていくことにある。
- `game/player/*` は現在エレナの互換投影だ。長期的な人格とキャラクターの記憶は、彼女の soul フォルダを正とする。
