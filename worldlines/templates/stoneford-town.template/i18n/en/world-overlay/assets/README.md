# assets/ — world art

Put this world's cover / key visual here, named `cover.png` (also supports .jpg / .webp).
Recognized cover names: cover · poster · thumbnail · preview · title.

- Shown in `neonrp web` as the scene banner at the top of the left column; a placeholder is shown when there's no image.
- Bundled with the world (`neonrp export-world` packs the whole directory, assets/ included, into the zip).
