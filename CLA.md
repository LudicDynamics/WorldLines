Version 1.0 · 2026-10-23

contribute, so that the project can keep shipping the code under its open-source licenses and in the products built on
it. You keep the copyright in your contribution; you are granting a license, not handing it over.

You accept this agreement by posting the sentence the CLA bot asks for in a comment on your pull request. You only need
to do this once; it covers every contribution you make to this repository after that.
